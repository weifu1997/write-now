# 父任务实施 — 仅集成，不改产品代码

## Ordered Checklist

1. 保持本父任务 `planning`，不要 `task.py start` 本目录。
2. 用户批准本规划后，按建议顺序分别 `task.py start` 子任务并实现。
3. 每个子任务提交前核对：不夹带工作区无关改动；有用户可见影响则走 release notes skill。
4. 三条都进 `beta` 后做交叉验收：
   - 新开一本 150 章：收官卷/最后一章像小结局；节奏曲线有起伏；跟进历史可收起且角标不为历史总数。
   - 一本 ≤60 章：紧凑全书结局合同仍在。
   - 运行记录仍无归档按钮。
5. 父任务只在三条子任务验收通过后归档。

## Validation

子任务各自的测试命令；父任务不跑额外全量套件。

## Explicitly Not Doing

- 父任务目录不改 `client/` / `server/` / `shared/` 产品代码。
