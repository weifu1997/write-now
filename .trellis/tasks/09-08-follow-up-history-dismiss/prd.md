# 导演跟进历史项可关闭且角标不计历史

## Goal

用户在导演跟进里能把已经不用处理的历史项收起；侧栏红角标只显示当前还要处理的条数，不再把取消、已替代、自动通过的旧记录算进去。

## User Value

跟进页现在像问题仓库：旧任务清不掉，角标一直红。新手会以为整本书一直有故障。运行记录不能拿来改状态，所以关闭入口必须出现在导演跟进这个源页面。

## Confirmed Facts

- `AutoDirectorFollowUpService.getOverview()` 的 `totalCount` 是全部投影项数量。
- `Sidebar.tsx` 在 `/auto-director/follow-ups` 上用该 `totalCount` 画破坏性红角标。
- 投影包含 `runtime_cancelled`、`runtime_replaced`、`auto_approval_completed` 等历史原因；取消项仍带重试动作，文案是“已取消待恢复”。
- 跟进详情没有归档/收起。小说工作区已有 `archiveTask("novel_workflow", taskId)`，归档写入 `taskCenterArchive`，跟进查询 `id notIn archivedIds`。
- 任务中心是只读“运行记录”，禁止放取消/归档/恢复按钮。
- `09-06-director-badge-semantics` 不覆盖本缺口。

## Requirements

1. 导演跟进详情对**历史项**提供“收起这条记录”。文案从用户角度说明：不再在跟进和角标里提醒，不删除小说，不取消正在跑的任务。
2. 可收起：已取消且用户不再恢复、已替代、已成功完成、自动通过记录、用户明确不再处理的失败项（失败项同时保留重试）。
3. 不可收起：排队中、运行中、等待确认、人工恢复中。这些不是历史，收起会把真阻塞藏掉。
4. 收起复用现有 `archiveTask` / 任务归档表，不新造第二套隐藏状态。自动通过记录若没有任务归档可挂，则从默认跟进列表排除或提供同等“不再显示”。
5. 侧栏角标改为**当前待处理计数**：校验阻塞 + 异常（失败/人工恢复）+ 待操作（等待确认/重规划/候选确认）。不计入已替代、已收起、自动通过、纯历史取消。
6. 运行中的自动推进可以在跟进列表里看到，但默认不进红角标，避免正常写作也一直红点。
7. 运行记录保持只读。跟进页的收起不是任务中心操作。
8. 收起后 overview、列表、侧栏角标同时下降；刷新后不会因为投影重建而回来。

## Acceptance Criteria

- [ ] 历史项详情出现“收起这条记录”，说明只是不再提醒。
- [ ] 运行中 / 等待确认 / 人工恢复项没有收起按钮。
- [ ] 收起调用已有归档能力；该 `directorTaskId` 从跟进列表和 overview 消失。
- [ ] 侧栏角标等于待处理计数，不等于 `totalCount`。
- [ ] 只有自动通过/已替代/已收起取消项时，角标为 0。
- [ ] 失败项收起后角标下降，但仍可从小说工作区或任务详情按原规则恢复（归档语义与现有“从任务列表移除”一致）。
- [ ] 单测覆盖：overview 待处理计数、归档后 list 排除、不可收起状态没有该动作。
- [ ] 不在 `/tasks` 运行记录页增加归档按钮。

## Out of Scope

- 批量清空全部历史（可后做；本期先单条收起）。
- 改变取消任务本身的运行时语义。
- 导演进度风险徽标（需复核/缺少规划资源）。
- 全书收束、紧张度曲线（兄弟任务）。

## Key Decisions

- 关闭历史 = 归档投影，不是再取消一次任务。
- 角标 = 待处理，不是记录总数。
- 动作放在导演跟进，符合“变更在源页面、运行记录只读”。
