# PRD：正文去 AI 味与追读读感改造（一期）

## 背景

对《宗门暴雷，我靠坏账重组飞升》抽样结论：表面反 AI 基本过关，但默认仍不满足「看不出是 AI + 读者放不下」。主缺口：

1. 对话/人物戏不足，大量章节偏审计旁白。
2. 章法同构：连续「查账→加压→更大窟窿」引擎。
3. 开书与高潮读感门槛过松，`continue` 即可过关。

## 目标（一期）

在不重做生产主链的前提下，抬高默认正文地板：

1. **对话与人物戏**：推进章必须有可见对白与人物互动，禁止整章纯流程旁白。
2. **章法去同构**：拆章阶段避免连续多章同一玩法引擎（尤其审计收网）。
3. **关键章读感加严**：开书前 3 章与卷高潮章，对 voice/engagement/对话稀疏更严，优先轻修而不是直接放行。

## 非目标

- 不重写《宗门暴雷》存量 150 章。
- 不做范文市场 / 跨书风格库。
- 不把局部读感问题升级为默认全局 `replan_required`。
- 不改 completion-first 对普通非关键章的总体策略。

## 验收标准

- [ ] Writer 提示词明确要求对话占比与人物互动场景，并禁止纯审计报告体。
- [ ] 拆章质量门能拦截「连续多章同属审计/收网引擎」的低多样性输出（语义重试可修复）。
- [ ] 开书前 3 章或卷高潮章：对话稀疏 / 追读力不足时，验收更倾向 `repairable` + 可执行修文，而不是无条件 `accepted/continue`。
- [ ] 普通非关键章仍可 `continue_with_risk` / 质量债，不因读感问题停全书。
- [ ] 有聚焦测试覆盖：对话稀疏检测、连续引擎多样性、关键章验收策略分支。
- [ ] 更新 wiki（章节生产链 / 读者体验）说明关键章门槛；release notes 写用户可见效果。

## 约束

- AI-first：玩法多样性由规划 AI 结构化输出 + 确定性后校验；不新增产品意图关键词路由。
- Prompt 变更走 `server/src/prompting/` 并升版本。
- 功能分支 `feature/09-09-prose-engagement-uplift` → 合入 `beta`。
